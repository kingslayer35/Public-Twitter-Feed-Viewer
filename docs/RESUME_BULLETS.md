## **🎨 FORMATTING TIPS**

### **Action Verbs to Use:**
- **Built, Engineered, Developed, Designed** (creation)
- **Implemented, Integrated, Architected** (technical)
- **Achieved, Delivered, Enabled** (results)
- **Reduced, Improved, Optimized** (performance)

### **Avoid These:**
- ❌ "Helped build" (own your work!)
- ❌ "Worked on" (too vague)
- ❌ "Created a simple..." (don't downplay)
- ❌ "Tried to implement" (did you or didn't you?)

### **Power Structure:**
```
[Action Verb] + [Technical Stack] + [What You Built] + [Key Metric] + [Business Impact]

Example:
"Engineered [verb] Chrome extension with Flask API [tech] enabling competitor feed monitoring [what]
with 200+ tweets/session [metric] reducing analysis time by 60% [impact]"
```
